Exploratory Data Analysis (EDA) Insights

Key findings uncovered during feature investigation and data preprocessing:

Attack vs. Defense
r = 0.45

Moderate positive correlation indicates defensive Pokémon often trade off rapid offensive velocity, forming distinct physical tank vs. offensive sweeper clusters.

Height vs. Weight
r = 0.67

Strong allometric scaling power-law between Pokémon stature (decimeters) and mass (hectograms), serving as critical physical indicators for element archetypes.

Dragon Type Supremacy
212.9 Exp

Dragon Pokémon hold the highest average Base Experience threshold (>210) and highest average Attack stat, followed closely by Steel (194.6) and Psychic (190.2).

End-to-End ML Pipeline Architecture

01
Data Ingestion

1,351 Pokémon instances loaded with 10 features: HP, Attack, Defense, Height, Weight, Base Exp, Types.

02
Preprocessing

Median imputation for missing numeric values; IQR outlier clipping; One-Hot Encoding for categorical types.

03
Feature Engineering

ColumnTransformer pipeline extracts 42 dense feature vectors combining scaled numericals and encoded types.

04
Tuned Inference

Production Random Forest classifier with 200 balanced decision trees executes multi-class prediction.
